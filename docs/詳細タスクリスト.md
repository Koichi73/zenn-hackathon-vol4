# 詳細実装タスクリスト

`docs/タスク.md` の内容を元に、実装レベルで具体化したタスクリストです。

## 1. ダッシュボード周り (Dashboard)

### 1-1. 認証・権限管理の強化
- [ ] **未ログイン時のUI制御**
    - `Dashboard` ページにて、未ログインユーザーに対してアップロードエリアを非表示にする、または無効化（グレーアウト）して「ログインしてください」を表示する。
    - ログイン状態は Firebase Auto SDK (`useAuthState` 等) から判定する。
- [ ] **アップロード時のガード**
    - アップロード関数（`handleUpload` 等）の冒頭で `currentUser` チェックを追加し、未ログインなら処理を中断・警告する。
- [ ] **テストユーザー作成**
    - Firebase Consoleにて、メール/パスワード認証のテスト用アカウントを作成する。
    - 認証情報を共有ドキュメント等に記載する。

### 1-2. 表示・文言の改善
- [ ] **ステータス表示の変更**
    - 動画リストのステータスバッジの文言を変更する。
        - `completed` → `Unshared` (未共有)
        - 共有中フラグがある場合 → `Shared` (共有中)
            - ※共有状態をFirestoreに保持するフィールドが必要な場合は追加する（例: `isShared: boolean`）。

## 2. 編集画面 (Editor)

### 2-1. UIクリーンアップ（不要要素の削除）
- [ ] **Step削除機能の撤去**
    - Stepカード内の「削除（ゴミ箱）」アイコン/ボタンを削除する。
- [ ] **案内テキスト・装飾の削除**
    - "Click on a mask/frame..." 等の操作説明テキストを非表示にする。
    - "Description" というラベル自体を消し、テキストエリアのみの表示にする（プレースホルダーで説明）。
    - 動画プレイヤーホバー時に表示される矢印等の装飾をCSSで非表示にする。
- [ ] **動画パネルの仕様変更**
    - **初期表示**: ページロード時は動画パネルを「最小化（閉じた）」状態で表示する。
    - **閉じるボタン廃止**: 動画自体の「×」ボタンを削除し、最小化ボタンのみで開閉を制御するUIにする。

### 2-2. 編集ロジックの実装・修正
- [ ] **マスク・ハイライト操作の保存**
    - Canvas上のオブジェクト（マスク範囲、赤枠）の変更イベント（`onDragEnd`, `onTransformEnd`）をフックする。
    - 変更された座標・サイズデータを、Firestoreの当該Stepドキュメントに更新送信する。
    - ※頻繁な書き込みを防ぐため、`debounce`（遅延書き込み）処理を入れるか、明示的な「保存」フローにするか検討（UX的には自動保存/debounce推奨）。
- [ ] **リロード時の動画非表示バグ修正**
    - ページリロード後に動画が表示されない原因を調査・修正する。
    - 疑わしい箇所: `useEffect` での動画URL初期化漏れ、または親コンポーネントからのProps受け渡しタイミングの問題。Stateに確実に永続化・復元されるようにする。

### 2-3. バックエンド処理
- [ ] **詳細解析の非同期化**
    - バックエンドの `/analyze`（または該当する解析API）の処理を `BackgroundTasks` に移行する。
    - APIは即時に `202 Accepted` を返し、実際の解析（Gemini APIコール等）はバックグラウンドで実行するように変更する。
    - フロントエンド側は、Firestoreのステータス更新を検知して解析完了を表示する（既存の仕組みがあれば流用）。

## 3. プレビュー・共有画面 (Preview / Share)

### 3-1. 表示内容の整理
- [ ] **ヘッダー・メタ情報の削除**

        - "Generated Manual", "Video Manual" タイトル
        - タイムスタンプ表示
        - AI生成の注釈文（"[!NOTE]..." 等）
- [ ] **シェアボタンの挙動変更**
    - ヘッダーの「Share」ボタンクリック時の挙動を変更する。
    - 現行: 共有リンク生成モーダル表示（あれば）
    - 変更後: 即座に現在の共有URLをクリップボードにコピーし、「リンクをコピーしました」等のToastを表示する。

## 5. 優先度別：時間があったらやるリスト (Nice to Have)

`docs/タスク.md` の「時間があったら」項目を、重要度とコスパの観点で優先度付けしました。

### Priority A: UXの穴を塞ぐ (ユーザーのストレス軽減・迷わせない)
最も優先すべき項目です。
- [ ] **動画解析中のローディング表示改善**
    - 「解析に約20~30秒かかります」等の目安時間を明示する。
    - ユーザーの不安感をなくすため、進捗状況（Stepメッセージ）をしっかりと見せる。
- [ ] **編集画面：マスク選択の解除**
    - Canvasの空白部分をクリックした際に、現在選択中のマスクやハイライトの選択を解除する処理を追加する。
    - 現状はずっと選択状態が残り操作しづらいため修正必須。
- [ ] **ログイン状態の可視化**
    - ヘッダーにユーザーアイコンやメールアドレスを表示し、「誰がログインしているか（あるいはしていないか）」を一目で分かるようにする。

### Priority B: アプリの「使い心地・見栄え」向上
- [ ] **ダッシュボードへのアップロードエリア配置**
    - ダッシュボード（一覧画面）の一番上にもアップロードエリアを配置する。
    - ユーザーがトップページに来てすぐに作業を開始できるようにする。
- [ ] **編集画面のデザイン調整 (脱・管理画面感)**
    - コンテンツ幅をPreview画面と合わせる（センタリング）。
    - 背景色を黒(`bg-neutral-900`等)から、明るめのグレーや枠線基調に変更し、ドキュメント編集ライクな雰囲気にする。

### Priority C: パフォーマンス・発展機能
- [ ] **Dashboardの表示高速化**
    - 取得件数が増えた場合に備え、`limit` 設定やページネーションを検討する。
    - ※現状の件数なら後回しでOK。
- [ ] **共有解除 (Unshare) 機能**
    - 一度共有したURLを無効化する機能。
    - 共有ボタンの再クリックでトグルできるようにする等。
- [ ] **Next.jsのエラー通知調査**
    - 開発中に頻発するToastエラーの原因特定と修正。実害が少なければ後回し。
